
# QuickNotes System Design

## Project Description

QuickNotes is a simple web-based note-taking application developed as part of the PLP Academy System Design assignment.

The project demonstrates frontend API integration, REST API design, relational database modelling and scalable system architecture.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Fetch API
- JSONPlaceholder
- SQL

## Running the Application

1. Clone the repository:

```bash
git clone https://github.com/ruthie-jk/quicknotes-system-design.git
```

2. Open the project folder:

```bash
cd quicknotes-system-design
```

3. Open `index.html` in a browser.

Alternatively, use the VS Code Live Server extension.

4. Click Load Notes to retrieve sample notes from JSONPlaceholder.

5. Use the form to create notes and the Delete button to remove them.

## What I Learned

Through this project, I learned:

1. How to use JavaScript Fetch API and asynchronous functions to communicate with external APIs.
2. How RESTful API endpoints use HTTP methods such as GET, POST, PUT, PATCH and DELETE.
3. How to design relational databases using primary keys, foreign keys and relationships.
4. How SQL JOIN operations retrieve related information from multiple tables.
5. How load balancing, caching and database replication support scalable systems.
6. How to organize a software project using Git and GitHub.

## Important Note

JSONPlaceholder is a testing API. POST and DELETE requests simulate data changes but do not permanently store them.
